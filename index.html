Before you order

ACBuy product links

Use ACBuy finds as a shortlist. For any Weidian, Taobao or 1688 listing you save, record the original seller URL, selected product variant, listing currency and last checked date.

When you check for a dead product link or an out-of-stock size, open the exact variant again. If the seller changed the listing title or product photos, verify the model and color before reusing the link.

Shoe and clothing size checks

For sneaker size conversion, measure both feet in centimeters and use the longer foot with the seller’s chart. Check whether the chart shows foot length or insole length.

For clothing size comparisons, measure a piece you already own. Match a hoodie’s chest width, a T-shirt’s body length, a jacket’s shoulder width or a pair of trousers’ inseam. For matching sets, confirm the top and bottom sizes separately.

ACBuy QC photos

Use warehouse quality control photos to compare the ordered colorway and size label with the seller page. For shoes, check outsole wear and stitching. For a jersey, check print placement. For a bag, ask for zipper and strap close-ups if those details are unclear.

If a measurement photo is available, check where the tape starts. Keep the order reference and check the return or exchange window before approving a parcel.

ACBuy shipping estimate

Compare the item price, domestic delivery, agent service fees and international shipping. Enter the destination postcode and packed parcel dimensions, then check actual weight against volumetric weight.

For US, UK and EU destinations, use a quote for your delivery country and check whether it includes taxes, customs charges or carrier handling fees. If consolidating orders, request a new quote for the combined parcel.

Frequently asked questions

What is an ACBuy spreadsheet?

An ACBuy spreadsheet is a list of product references organized for comparison. An entry can include a seller link, a category and notes on sizing or photos.

Where do the category links lead?

The category links open Hipobuyfind. This is an independent guide with no official affiliation with ACBuy or the pictured brands.

Can I order any spreadsheet link through ACBuy?

Check the current seller page and your agent's accepted marketplaces and product restrictions before paying. A saved link can point to an unavailable variant or an unsupported listing.

Do QC photos prove that an item is authentic?

QC photos help you compare the received item with the variant you chose and spot visible defects. For authenticity, use verifiable seller documentation or a qualified authentication service.

How do I compare shipping quotes?

Use the same destination and packed parcel dimensions for each quote. Check how the carrier calculates billable weight and which charges the quote includes.
